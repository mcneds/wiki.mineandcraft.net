From tiny decorative blocks to dragon loot, these datapacks change a few of the things you can collect on mineandcraft.net.

## Mini blocks

Use a **stonecutter** to craft supported blocks into miniature versions. These are player-head items textured to look like blocks. Put a supported block into the stonecutter and select its mini-block output when available.

This server lists **Mini Blocks 1.1.8**. Its official description specifies stonecutting; older wandering-trader instructions are not the instructions for this listed pack.

## More mob heads

Killing a mob can drop its head. This is a chance-based addition, not a guaranteed head on every kill. The exact drop chances have not been verified for the server.

## Player head drops

When one player kills another, the killed player drops a head displaying the killer's name. The pack provides a mechanic, not permission to kill someone. The [Be civil](/wiki/rules/) rule still applies.

## Silence mobs

Rename a name tag in an anvil using one of these exact names, then apply it to a mob:

- `Silence me`
- `silence me`
- `silence_me`

The pack silences the named mob.

## Double shulker shells

Shulkers drop **two shells** with the listed pack. No extra player command is required.

## Dragon drops

The Ender Dragon drops a **dragon egg and an elytra** when it dies with this pack active.

## Ender chest always drops

The listed pack allows an ender chest to drop without Silk Touch.
