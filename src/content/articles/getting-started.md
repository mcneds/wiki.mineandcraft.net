**mineandcraft.net** is an invite-only Minecraft community with a relaxed, Hermitcraft-inspired approach to survival. Build something, get to know the other players, and help make a world worth coming back to.

## Joining the server

An invitation is required for **both Java and Bedrock players**. Arrange access with the server owner before trying to connect. There is no public application link on this wiki.

### Java Edition

1. Get your invitation and confirm that your in-game name has been approved.
2. Check the supported Minecraft version with the owner. The supplied mod and datapack inventory targets **26.3**, but filenames alone do not establish which client versions can currently connect.
3. Open **Multiplayer → Add Server** and enter `mineandcraft.net` as the server address.
4. Save the entry and join.

### Bedrock Edition

Bedrock access is provided through **Geyser and Floodgate** on the Java server. Ask the owner for the Bedrock address and port with your invitation; the port has not yet been published here. Custom-server entry also depends on the device you play on.

The server follows Java gameplay rules. Do not assume that every Bedrock farm design or redstone tutorial will behave the same way here.

## What should I install?

Datapacks run with the server world; you do not install the server's datapack ZIPs on your client to use their features. The [mod inventory](/wiki/mods-and-datapacks/) includes server features, libraries, and client performance tools. It is **not** a list of required client downloads. Confirm any client requirements with the owner.
